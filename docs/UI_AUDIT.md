# UI audit

Date: 16 October 2026. This is an audit and recommendation document; no application code was changed.

Read in full: [AGENTS.md](../AGENTS.md), [00_START_HERE.md](00_START_HERE.md) and the [visual reference](reference/coastal-drone-mock.html). Scope: sign in, watch floor, feed wall, incident list, incident review, zones and rules, models and health; full-screen feed, evidence, new-zone and comparison dialogs; shared shell, notifications and presenter mode. Screens listed only in the source of truth are not implemented screens and were not treated as broken routes.

Method: source inspection plus local Edge browser checks at 1366 × 768, 1920 × 1080, 1024 × 768 and 768 × 1024. Measurements below use the default supervisor fixtures unless specified. Desktop layouts produced no page-level horizontal overflow. Tablet problems are mostly priority displacement and internal scrolling, rather than content escaping the document. No runtime errors occurred in the normal browser paths checked.

Evidence tags: **Browser** means reproduced in the rendered UI; **Source** means an implementation gap or risk identified from code, without injecting that failure; **Review** means a visual or interaction assessment. Performance findings are source-level risks, not measured latency regressions. Full keyboard and assistive-technology certification, real video decoding, real network failures and physical tablet testing were outside this audit.

Impact: **High** can hide critical monitoring information or create a consequential action mistake; **Medium** impairs task clarity, accessibility or recovery; **Low** affects consistency, polish or future scalability. Findings are sorted by impact. Confirmation recommendations need separate implementation approval; none were added during this audit.

Accessibility checks found no unnamed rendered buttons/inputs/selects in the sampled normal views. Explicit keyboard focus styling is broadly present; native dialogs provide modal focus containment and restore the opener. A rendered HTML text/background check found no ratios below 4.5:1 on sign in, watch floor, feed wall, incident list, zones, models and Compare versions in their sampled default states. That automated check excludes SVG/canvas imagery, map halos, translucent media overlays and untested states, so it is not a full contrast certification. Detection text uses ink on panel-filled labels; map labels have panel halos. Remaining issues are recorded above rather than inventing contrast or missing-label violations.

With 18 fixture feeds, only the current page's 9, 4 or 1 tiles is mounted; off-page feeds are sliced out before rendering. Page/layout retention already exists and is not a finding. Live telemetry subscriptions target individual fields/feeds in the main consumers; no claim is made that all screens rerender on every emitter tick. The specific remaining update risks are L13–L17. No new dependencies, source edits, commits or lint/typecheck/build runs were needed for this documentation-only audit.
